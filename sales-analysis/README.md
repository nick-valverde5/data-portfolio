# Sales Performance Dashboard

## Project Overview
This project analyzes retail sales data using SQL and Tableau to identify 
regional performance trends, top product categories, and actionable insights 
for business growth.

---

## Business Problem
Sales teams need clear visibility into which regions, products, and time 
periods are driving revenue. This analysis provides a centralized dashboard 
to support data-driven decision making.

---

## Tools Used
- MySQL
- Tableau
- Excel
- GitHub

---

## Key Questions Answered
1. Which region generates the most revenue?
2. What product category performs best?
3. How do sales trend over time?
4. Which customer segment drives the most sales?

---

## Key Findings
- Identified top performing regions and product categories driving majority of revenue
- Discovered seasonal sales trends useful for inventory and staffing planning
- Highlighted underperforming segments with opportunity for growth

---

## Business Recommendations
- Invest more resources in top performing regions
- Focus promotions on high margin product categories
- Use seasonal trends to plan inventory and staffing in advance

---

## Dashboard Features
- Regional sales comparisons
- Product category breakdowns
- Time period trend analysis
- Interactive filtering
