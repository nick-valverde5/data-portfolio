# Data Analytics Portfolio

This repository showcases data analysis projects using Python, SQL, and data visualization to solve real-world business problems.

## Projects

### 📊 Sales Analysis
Analyzed retail sales data to identify top-performing products, regional trends, and revenue growth patterns.

**Tools Used:**
- Python (Pandas, Matplotlib)
- Jupyter Notebook

**Key Insights:**
- Eldon File Cart – Single Width is the top-performing product
- Central region generates the highest sales
- Sales show a consistent upward trend over time
