
# Data Portfolio

Welcome to my data analytics portfolio. This repository contains projects using Python, SQL, data cleaning, exploratory analysis, and data visualization to answer business questions.

## Projects

### 1. Sales Analysis
Analyzed SuperStore sales data to identify top products, strongest regions, and sales trends over time.

**Tools Used:** Python, Pandas, Matplotlib, Jupyter Notebook

**Key Insights:**
- Eldon File Cart – Single Width was the top-performing product.
- The Central region generated the highest sales.
- Sales showed an upward trend over time.
